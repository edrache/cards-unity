# NPC Deck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a special NPC character deck: slot effects can draw an NPC card, which shows narrative text and triggers an optional mechanical effect (add card to hand, damage a threat bar, increment the opponent clock).

**Architecture:** `NpcCardDefinition` (SO) holds character name, portrait, narrative text, and a list of `NpcEffect` (serializable class with `NpcEffectAction` enum). `NpcDeckDefinition` (SO) holds an ordered/shuffled card list. `NpcDeckState` (runtime) manages draw/discard piles and the currently active NPC. `SlotEffectAction.DrawNpcCard` triggers the draw from slot effects. `TurnController` gains a nullable `NpcDeckState` parameter, fires `OnNpcCardDrawn(NpcCardDefinition)` on draw, and otherwise stays unchanged. `ChallengeController` subscribes to the event, evaluates mechanical effects directly (it already holds `_hand`, `_threatState`, `_opponentClock`), and refreshes `NpcCardView`. `NpcCardView` MonoBehaviour shows portrait + name + text, hidden when no active NPC.

**Tech Stack:** Unity 6, C#, NUnit (Unity Test Framework), uGUI, existing `DeckState` pattern.

**Prerequisite:** `2026-05-03-status-cards.md` plan completed — TurnController constructor at that point already has `StatusCollection` parameter before `draftValue`.

- [ ] **Step 3: Implement NpcDeckState**

```csharp
using System;
using System.Collections.Generic;

namespace CardsUnity
{
    public class NpcDeckState
    {
        private readonly List<NpcCardDefinition> _drawPile    = new List<NpcCardDefinition>();
        private readonly List<NpcCardDefinition> _discardPile = new List<NpcCardDefinition>();

        public NpcCardDefinition ActiveCard   { get; private set; }
        public int               DrawCount    => _drawPile.Count;
        public int               DiscardCount => _discardPile.Count;

        public NpcDeckState(NpcDeckDefinition definition, Random rng)
        {
            var cards = new List<NpcCardDefinition>(definition.cards);

            if (definition.shuffleOnInit && rng != null)
            {
                for (int i = cards.Count - 1; i > 0; i--)
                {
                    int j = rng.Next(i + 1);
                    (cards[i], cards[j]) = (cards[j], cards[i]);
                }
            }

            _drawPile.AddRange(cards);
        }

        public NpcCardDefinition Draw(Random rng)
        {
            if (ActiveCard != null)
            {
                _discardPile.Add(ActiveCard);
                ActiveCard = null;
            }

            if (_drawPile.Count == 0)
            {
                if (_discardPile.Count == 0)
                    return null;

                ShuffleDiscardIntoDrawPile(rng);
            }

            ActiveCard = _drawPile[_drawPile.Count - 1];
            _drawPile.RemoveAt(_drawPile.Count - 1);
            return ActiveCard;
        }

        private void ShuffleDiscardIntoDrawPile(Random rng)
        {
            _drawPile.AddRange(_discardPile);
            _discardPile.Clear();

            for (int i = _drawPile.Count - 1; i > 0; i--)
            {
                int j = rng.Next(i + 1);
                (_drawPile[i], _drawPile[j]) = (_drawPile[j], _drawPile[i]);
            }
        }
    }
}
```

```csharp
private void HandleNpcCardDrawn(NpcCardDefinition card)
{
    if (card?.effects != null)
    {
        foreach (var effect in card.effects)
        {
            if (effect != null)
                ApplyNpcEffect(effect);
        }
    }

    RefreshUI();
}

private void ApplyNpcEffect(NpcEffect effect)
{
    switch (effect.action)
    {
        case NpcEffectAction.AddCardToPlayerHand:
            if (effect.cardToAdd != null)
                _hand.Add(new CardInstance(effect.cardToAdd));
            break;

        case NpcEffectAction.DamageToThreat:
            _threatState?.GetBar(effect.targetCardType)?.TakeDamage(effect.actionValue);
            break;

        case NpcEffectAction.IncrementOpponentClock:
            _opponentClock?.Increment(effect.actionValue);
            break;
    }
}
```

```csharp
using TMPro;
using UnityEngine;
using UnityEngine.UI;

namespace CardsUnity.UI
{
    public class NpcCardView : MonoBehaviour
    {
        [SerializeField] private GameObject       panel;
        [SerializeField] private Image            portraitImage;
        [SerializeField] private TextMeshProUGUI  nameLabel;
        [SerializeField] private TextMeshProUGUI  narrativeLabel;

        public void Refresh(NpcCardDefinition card)
        {
            bool hasCard = card != null;

            if (panel != null)
                panel.SetActive(hasCard);

            if (!hasCard)
                return;

            if (portraitImage != null)
                portraitImage.sprite = card.portrait;

            if (nameLabel != null)
                nameLabel.text = card.characterName;

            if (narrativeLabel != null)
                narrativeLabel.text = card.narrativeText;
        }
    }
}
```
